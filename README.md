# MontesWorks LLC website

A mobile-friendly static website using HTML, CSS, and JavaScript.

## Files
- `index.html` — text, sections, and contact links
- `style.css` — colors, layout, and mobile design
- `script.js` — mobile menu and email-based estimate request
- `images/` — put your logo and project photos here

## Preview
Open `index.html` in a browser. For a better local preview, run `python -m http.server 8000` in this folder and open http://localhost:8000.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of a public GitHub repository.
2. In repository Settings > Pages, select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
3. Visit the Pages URL shown in Settings > Pages once deployment completes.

## Notes
- The estimate form uses `mailto:` and requires the visitor to have an email app configured; it does not send data to a server.
- Replace the placeholder MW mark with the official logo when available.
- Add real project photos with permission.
- Verify service area and services before publication; do not advertise licensed services without appropriate authorization.
